1. Introduction to Probability

Visual explanation · Probability scale
0 · Impossible0.5 · Equally likely1 · Certain

The marker travels from 0 to 1: the closer a probability is to 1, the more likely the event is to occur.

Probability — a numerical measure of the likelihood that an event will occur. Probability values are always assigned on a scale from 0 to 1.
  • A probability near 1 indicates an event is almost certain to occur.
  • Other probabilities between 0 and 1 represent degrees of likelihood that an event will occur.

1.1 Basic Terms

Experiment — a process that generates well-defined outcomes.
Sample Space (S) — the set of all experimental outcomes.
Sample Point — an experimental outcome is also called a sample point.
Event — a collection of sample points.

Examples of experiments include tossing a coin and rolling a die.

ExperimentSample spaceSample point
Tossing a coinS = {Head, Tail}Head or Tail

Each coin toss doubles the number of possible outcomes: 2 × 2 = 4 for two tosses. The same multiplication principle extends to more steps.

Three counting rules are used to count experimental outcomes:

  1. Multiple-step experiments
  2. Combinations
  3. Permutations

2.1 Multiple-Step Experiments

A multiple-step experiment involves more than one experiment performed together, e.g. two coins or two dice.

Example: Tossing two coins:

S = {HH, HT, TH, TT}

Sequence of k trials:

  • n₁ = number of possible outcomes from step 1
  • n₂ = number of possible outcomes from step 2
  • … and so on up to step k.
Counting rule: Total outcomes = (n₁)(n₂) … (nₖ)

For two coins: n₁ = 2 and n₂ = 2, so the total number of outcomes is 4.

Tree Diagram

Tree diagram — a graphical representation that helps in visualizing a multi-step experiment.

For three coin tosses, each toss has two possible outcomes (H or T), giving 2 × 2 × 2 = 8 possible outcomes.

S = {HHH, HHT, HTH, HTT, THH, THT, TTH, TTT}

2.2 Combinations

Combinations allow one to count the number of experimental outcomes when the experiment involves selecting n objects from a set of N objects.
C(N, n) = N! / [n!(N − n)!]

Where:

  • N! = N(N − 1)(N − 2) … (2)(1)
  • n! = n(n − 1)(n − 2) … (2)(1)
  • 0! = 1

2.3 Permutations

Permutations allow one to count the number of experimental outcomes when n objects are to be selected from a set of N objects, where the order of selection is important.
P(N, n) = n! C(N, n) = N! / (N − n)!
Combination vs. permutation: Use combinations when order does not matter, and permutations when order matters.

3.1 Basic Requirements

  1. The probability assigned to each experimental outcome must be between 0 and 1, inclusively. If Eᵢ denotes the ith experimental outcome and P(Eᵢ) its probability, this requirement is written:
0 ≤ P(Eᵢ) ≤ 1   for all i
  1. The sum of the probabilities for all the experimental outcomes must equal 1. For n experimental outcomes, this requirement is written:
P(E₁) + P(E₂) + … + P(Eₙ) = 1

4. Some Basic Relationships of Probability

Visual explanation · Events and Venn diagrams
Union: A or B or bothIntersection: both A and BOutside A: complement Aᶜ

The shared middle region represents A ∩ B. The full area covered by either circle represents A ∪ B.

4.1 Complement of an Event

Given an event A, the complement of A is defined to be the event consisting of all the sample points that are not in A.

Aᶜ denotes the complement of event A.

P(A) = 1 − P(Aᶜ)

4.2 Addition Law

The addition law involves two operations on events: union and intersection.

Union of two events: The union of A and B is the event containing all the sample points belonging to A or B or both.
A ∪ B
Intersection of two events: Given two events A and B, the intersection of A and B is the event containing the sample points belonging to both A and B.
A ∩ B
Addition law: Provides a way to compute the probability that event A or event B or both occur.
P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

4.3 Mutually Exclusive Events

Two events are said to be mutually exclusive if the events have no sample points in common.

Conditional probability narrows the reference group to B first, then asks how likely A is within that group: P(A | B).

Conditional probability is the probability that an event will occur given that another event has already occurred.

If A and B are two events, the conditional probability of A given B is written P(A | B) and read as “the probability of A given B has already occurred.”

A

The event whose probability is to be determined.

B

The event that has already occurred.

The notation P(A | B) represents the probability of A under the condition that B has occurred.

7. Joint Probability

P(A ∩ B) = P(A) × P(B | A)

The overlap represents outcomes where A and B happen together. The multiplication rule uses one event's probability and the conditional probability of the other.

Definition: The probability of the intersection of two events is called joint probability. It is written as P(A and B) or P(A ∩ B).

7.1 Multiplication Rule

The probability of the intersection of two events is obtained by multiplying the marginal probability of one event by the conditional probability of the second event.
P(F ∩ A) = P(F) × P(A | F)Marginal probability × Conditional probability

7.2 Marginal, Joint and Conditional Probability in a Contingency Table

  • Joint probability appears in the body of the table.
  • Marginal probability appears in the margin of the table.
  • Conditional probability refers to the probability of an event given that another event has already occurred.
